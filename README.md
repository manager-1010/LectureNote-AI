# LectureNote AI

LectureNote AI is an open-source desktop tool designed to help students turn lecture recordings into readable notes.

The goal is to make lecture review faster and easier, especially for students who have long audio or video recordings and do not want to manually transcribe everything.

## Features

- Batch import MP3, M4A, WAV, and MP4 files
- Local speech-to-text transcription using faster-whisper
- Save the original raw transcript
- Optional AI-generated lecture notes
- Export notes as Markdown files
- Custom output folder
- Designed for Windows desktop use

## Why I Built This

Students often record lectures but reviewing long recordings takes a lot of time.

LectureNote AI aims to create a simple workflow:

**Lecture recording → Transcript → Structured notes**

The project focuses on making this process easy to use and accessible without requiring complicated technical setup.
